# Server

Серверная часть приложения для управления элементами трубопроводов на Rust. Предоставляет REST API для аутентификации
пользователей и CRUD операций над секциями, цепями, аксессуарами и пользователями. Использует SQLite базу данных для
хранения данных.

## Функциональность

- **Аутентификация и управление пользователями**: Вход в систему, управление учетными записями пользователей с
  различными уровнями доступа (User, Economist, Manager, Administrator, Programmer).
- **Управление секциями трубопроводов**: Добавление, получение, обновление и удаление секций с параметрами: тип
  трубопровода (Lamellar, Madal, Rolgang), тип секции, длина, цена, магнитные свойства, материал сторон, радиус, угол,
  связанные цепи.
- **Управление цепями**: CRUD операции над цепями с параметрами: тип трубопровода, тип цепи, материал, цена, магнитные
  свойства, название.
- **Управление аксессуарами**: Добавление, получение, обновление и удаление аксессуаров с названием и ценой.
- **Расчеты**: Эндпоинт для расчета стоимости выбранных блоков трубопроводов на основе секций, цепей и аксессуаров.
- **База данных**: Автоматическое создание таблиц при первом запуске.

## API Эндпоинты

- `POST /login` - Аутентификация пользователя
- `GET /section/get` - Получение всех секций
- `POST /section/add` - Добавление секции
- `POST /section/update` - Обновление секции
- `POST /section/delete` - Удаление секций
- `GET /chain/get` - Получение всех цепей
- `POST /chain/add` - Добавление цепи
- `POST /chain/update` - Обновление цепи
- `POST /chain/delete` - Удаление цепей
- `GET /accessories/get` - Получение всех аксессуаров
- `POST /accessories/add` - Добавление аксессуара
- `POST /accessories/update` - Обновление аксессуара
- `POST /accessories/delete` - Удаление аксессуаров
- `GET /user/get` - Получение всех пользователей (только для Programmer)
- `POST /user/add` - Добавление пользователя (только для Programmer)
- `POST /user/update` - Обновление пользователя (только для Programmer)
- `POST /user/delete` - Удаление пользователей (только для Programmer)
- `POST /calculation` - Расчет стоимости выбранного набора элементов

## Зависимости

- Rust (cargo)
- rusqlite
- axum (для HTTP сервера)
- tokio (для асинхронности)

## Запуск

```bash
cargo run
```

Сервер запускается на `127.0.0.1:3000`. База данных создается автоматически при первом запуске в файле `database.db`.
