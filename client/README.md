# Client

Клиентское приложение на Rust для управления элементами конвейеров. Предоставляет графический интерфейс на базе egui для
взаимодействия с сервером: просмотр, добавление, редактирование и удаление секций, цепей, аксессуаров и пользователей, а
также создание запросов на расчет стоимости.

## Функциональность

- **Аутентификация**: Экран входа с полями логина и пароля. Подключение к серверу по адресу `127.0.0.1:3000`.
- **Dashboard**: Главная панель с навигацией по разделам в зависимости от уровня доступа пользователя.
- **Создание запросов (Calculations)**: Интерфейс для формирования блоков трубопроводов:
    - Выбор секций из списка с фильтрацией по типу трубопровода.
    - Указание параметров длины (ширина для Lamellar/Madal, ширина и расстояние между роликами для Rolgang).
    - Добавление цепей к блокам (фильтрация по типу трубопровода секции).
    - Добавление аксессуаров к блокам.
    - Расчет итоговой стоимости выбранного набора элементов.
- **Управление секциями**: Просмотр списка секций в табличном виде, добавление новых, редактирование существующих (
  изменение параметров), удаление. Доступно для уровней Economist, Manager, Administrator, Programmer.
- **Управление цепями**: Аналогично секциям, CRUD операции над цепями. Доступно для уровней выше User.
- **Управление аксессуарами**: Просмотр, добавление, редактирование и удаление аксессуаров. Доступно для уровней выше
  User.
- **Управление пользователями**: Только для уровня Programmer - просмотр, добавление, редактирование и удаление
  пользователей.
- **Модальные окна**: Для подтверждения удаления, добавления/редактирования элементов.

## Экраны приложения

- **Login**: Аутентификация
- **Dashboard**: Навигация
- **Calculations**: Формирование и расчет запросов
- **Sections**: Управление секциями
- **Chains**: Управление цепями
- **Accessories**: Управление аксессуарами
- **Users**: Управление пользователями (только Programmer)

## Уровни доступа

- **User**: Только просмотр и создание расчетов
- **Economist/Manager/Administrator/Programmer**: Дополнительно редактирование секций, цепей, аксессуаров
- **Programmer**: Полный доступ, включая управление пользователями

## Сценарий использования

Типичный сценарий работы с приложением для пользователя с уровнем доступа User (базовый пользователь):

1. **Запуск приложения**: Пользователь запускает клиентское приложение командой `cargo run`.
2. **Аутентификация**: Открывается экран входа. Пользователь вводит логин и пароль, нажимает "Войти". При успешной
   аутентификации приложение переходит на Dashboard.
3. **Навигация по Dashboard**: На главной панели отображаются доступные кнопки: "Создать запрос" (для формирования
   расчетов). Пользователь нажимает "Создать запрос".
4. **Формирование запроса (Calculations)**:
    - Приложение загружает списки секций, цепей и аксессуаров с сервера.
    - Пользователь нажимает "Добавить блок" для создания нового блока трубопровода.
    - В модальном окне выбирает секцию из списка (фильтруется по типу трубопровода).
    - Указывает параметры длины: для Lamellar/Madal - ширину, для Rolgang - ширину и расстояние между роликами.
    - Подтверждает добавление блока.
    - Для добавления цепей к блоку: нажимает "Добавить цепь", выбирает цепь из списка (фильтруется по типу трубопровода
      секции).
    - Аналогично добавляет аксессуары к блоку.
    - Повторяет процесс для создания нескольких блоков.
5. **Расчет стоимости**: После формирования всех блоков пользователь нажимает "Расчитать сумму". Приложение отправляет
   запрос на сервер, получает итоговую стоимость и отображает ее в модальном окне.
6. **Выход**: Пользователь может вернуться на Dashboard кнопкой "Назад" и при необходимости выйти из системы кнопкой "
   Авторизация".

Для пользователей с более высокими уровнями доступа (Economist и выше) дополнительно доступны разделы редактирования:

- В Dashboard появляются кнопки "Редактировать секции", "Редактировать цепи", "Редактировать аксессуары".
- В разделе редактирования: просмотр списка в таблице, кнопки "Добавить" для создания новых элементов, "Изменить" для
  редактирования существующих, "Удалить" с подтверждением.
- Для Programmer дополнительно доступен раздел "Редактировать пользователей" с аналогичными функциями (кроме удаления
  пользователя с id=1).

## Зависимости

- Rust (cargo)
- egui (графический интерфейс)
- eframe (фреймворк для egui приложений)
- reqwest (HTTP клиент для связи с сервером)
- egui-modal (модальные окна)

## Запуск

```bash
cargo run
```

Приложение подключается к серверу на `127.0.0.1:3000`. Требуется предварительный запуск сервера.
