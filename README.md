# Pipeline Management App

Это приложение для управления хранилищем данных о деталях промышленных конвейеров

## Части приложения

- **Серверная часть**: [server/README.md](server/README.md) - Обработка запросов от клиента и управление базой данных.
-
    - **Клиентская часть**: [client/README.md](client/README.md) - Графический интерфейс для формирования готовых
      конвейеров из отдельных деталей

## Запуск

См. инструкции в соответствующих README файлах частей.
